# 🧠 Гибридная NLP-модель выявления депрессии и суицидальных состояний

> Курсовая работа: **"Система выявления маркеров кризисных состояний в текстах на основе трансформерных эмбеддингов и градиентного бустинга"**

## 📋 Резюме

Проект представляет собой **гибридную систему машинного обучения**, которая анализирует тексты пользователей для выявления признаков депрессивного и суицидального состояния. Система объединяет:

- **Семантические эмбеддинги** (модель `all-mpnet-base-v2`, 768 измерений) для глубокого понимания контекста.
- **Лингвистический анализ** (31 признак, база из 460 уникальных маркеров по 6 категориям) для интерпретируемости.
- **Классификатор CatBoost** для итоговой оценки риска с оптимальным порогом 0.495.
- **Интеграцию механизма NLI** (распознавание явного отрицания намерений, например, "я не хочу умирать") для снижения ложных срабатываний.
- **SHAP-визуализацию** для обеспечения прозрачности и объяснимости предсказаний модели.

## 📁 Файлы проекта

| Файл | Назначение |
|------|-----------|
| `lexicons.py` | База из 460 маркеров депрессии по 6 категориям. |
| `feature_extractor.py` | Модуль извлечения 31 лингвистического признака. |
| `run_all.ipynb` / `.py`| Основной скрипт/ноутбук: предобработка, обучение CatBoost, оценка, визуализация. |
| `bot.py` | Telegram-бот на базе `aiogram 3.x` с поддержкой мультиязычности (langdetect + deep-translator). |
| `shap_explainer.py` | SHAP-анализ важности признаков (Feature Importance). |
| `dataset_loader.py` | Загрузчик датасета и генератор аугментированных данных. |
| `requirements.txt` | Зависимости проекта (CatBoost, SentenceTransformers, SHAP и др.). |
| `cb_suicide_model.cbm`* | Сохраненная обученная модель CatBoost (генерируется после запуска). |
| `model_config.json`* | Конфигурация: метрики, порог, имена признаков (генерируется после запуска). |

*(Файлы весов модели не включены в репозиторий и генерируются локально при запуске пайплайна обучения).*
