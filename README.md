> Курсовая работа: **"Разработка гибридной модели машинного обучения для выявления признаков депрессивных и суицидальных состояний на основе анализа текстового цифрового следа"**

## Резюме

Проект разрабатывает **гибридную систему машинного обучения**, которая анализирует тексты пользователей (социальные сети, мессенджеры) для выявления признаков депрессивного и суицидального состояния. Система объединяет:

- **Глубокое NLP** (sentence-transformers + RuBERT fine-tuning) для понимания семантики
- **Лингвистический анализ** (460+ маркеров в 6 категориях) для интерпретируемости
- **Методы ансамблирования** (CatBoost + Deep Learning) для максимальной точности
- **SHAP-визуализацию** для объяснения предсказаний

## Модели

### 1. CatBoost (Гибридная модель)

**Вход:**
- Эмбеддинги (384-dim): `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
- Лингвистические признаки (30): лексиконы, синтаксис, эмоциональные индексы

**Параметры:**
- `iterations=300-500`
- `learning_rate=0.05`
- `depth=4` (регуляризация)
- `l2_leaf_reg=3.0`
- `class_weights=[1.0, 2.0]` (баланс)

**Преимущества:**
- Интерпретируемость (SHAP, feature importance)
- Работает на CPU
- Быстрое предсказание (< 50 мс)
- Устойчивость к переобучению

### 2. RuBERT Fine-tuning (Deep NLP)

**Архитектура:**
- `DeepPavlov/rubert-base-cased` (12 слоёв, 768-dim)
- [CLS]-token + dropout + classification head
- AdamW optimizer, linear warmup

**Варианты:**
- **Full fine-tuning:** обучаются все слои (максимальная точность)
- **Light fine-tuning:** заморозка BERT, обучается только head (быстрее)
- **Feature extraction:** LogReg на [CLS]-эмбеддингах (baseline)

**Преимущества:**
- Учитывает контекст и порядок слов
- Работает на русском языке (родная лемматизация)
- State-of-the-art качество

### 3. Ансамбль

Объединяет CatBoost и RuBERT через взвешенное среднение:
```
p(ансамбль) = w_catboost * p_catboost + w_rubert * p_rubert
```

Веса подбираются на валидации по F1-score.

## Лингвистические признаки (30+)

### Категории лексиконов

| Словарь | Маркеров | Назначение |
|---------|----------|------------|
| `HOPELESSNESS` | 70+ | Безысходность, потеря смысла, пустота |
| `SUICIDAL_IDEATION` | 70+ | Суицидальные мысли, планы, прощания |
| `DEPRESSION_EMOTIONAL` | 90+ | Эмоциональная депрессия, апатия, тревога |
| `COGNITIVE_DISTORTIONS` | 80+ | Абсолютизация, самообвинение, катастрофизация |
| `SOCIAL_ISOLATION` | 50+ | Одиночество, отчуждение, отсутствие связей |
| `PHYSICAL_SYMPTOMS` | 100+ | Соматические симптомы, лекарства, терапия |
| `INTENSIFIERS` | 60+ | Усилители эмоций ("очень", "невыносимо", "замучало") |
| `POSITIVE_MARKERS` | 80+ | Контрастные позитивные маркеры |

### Извлекаемые признаки

| Группа | Признаки | Пример |
|--------|----------|--------|
| Базовые метрики | 6 | text_length, word_count, lexical_diversity |
| Лексиконные частоты | 9 | hopelessness_freq, suicidal_freq, depression_freq |
| Структурные | 6 | i_pronoun_freq, negation_freq, caps_freq |
| Эмоциональные индексы | 5 | negative_index, positive_index, emotional_balance |
| Композитные | 4 | depression_index, suicide_risk_index, risk_ratio |

**Ключевые инновации:**
- **Когнитивные искажения:** частота абсолютизирующих выражений ("всегда", "никто", "всё пропало")
- **Интенсификаторы:** усиливают вес маркеров ("невыносимо" + "грусть" > просто "грусть")
- **Эмоциональный баланс:** разница между позитивными и негативными индексами
- **Risk/Protective ratio:** отношение риск-факторов к защитным

## Безопасность и этика

?? **Важные предупреждения:**

1. **Не медицинский диагноз.** Бот — инструмент скрининга, не заменяет психиатра.
2. **Анонимность.** User ID хешируется SHA-256, текст не сохраняется полностью.
3. **Ложные срабатывания.** Возможны false positives (ирония, цитаты, художественные тексты).
4. **Кризисная помощь.** При высоком риске бот предлагает телефоны доверия.
5. **Гуманный подход.** Не используйте для массовой слежки или принудительных мер.

## Расширения (идеи для развития)

- **Мультимодальность:** добавить анализ голоса (Whisper + prosody) или видео (мимика)
- **Временная динамика:** отслеживать изменение риска во времени по истории сообщений
- **Explainability:** SHAP-визуализация для каждого предсказания
- **Мультиязычность:** дообучение на арабском, китайском, испанском
- **Классификация тяжести:** не бинарный, а порядковый класс (низкий/средний/высокий риск)
